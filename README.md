# Task Manager 

Учебный проект - консольный менеджер задач на Python + SQLite.

## Возможности
- Добавление задачи с описанием
- Просмотр всех задач
- Фильтрация по айди
- Изменение статуса задачи
- Удаление задачи

## Стек
- Python 3
- SQLite

## Установка и запуск
1. Клонировать репозиторий:
   git clone https://github.com/staiwers/task-manager.git
   cd task-manager
   
2. Создать виртуальное окружение и активировать:
   python3 -m venv venv

3. Запустить приложение:
   python app.py

## Структура проекта:
- CRUD.py - функции CRUD
- app.py - CLI интерфейс
- init_db.py - создание БД и таблицы
- start_logo.py - стартовый логотип
